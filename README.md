## アプリケーション名
ブロック崩しゲーム

## 概要

学校の授業でチーム制作したブロック崩しゲームです。

チームメンバーがそれぞれステージを担当して制作し、
私はStage 4を担当しました。

元のゲームは、スコアに応じて次のステージへ進む形式で、
BGMも使用していました。

今回は自分が担当したStage 4を単体で遊べる形にして公開しています。
そのため、公開版ではすべてのブロックを破壊するとゲームクリアとなります。
なお、現在公開しているWeb版ではBGMは再生されません。


## URL
https://oomuro123.github.io/block-game/

## 利用方法

上記のURLにアクセスするとゲーム画面が表示されます。

ゲーム画面を一度クリックするとカウントが開始され、
約3秒後にゲームが自動的に開始します。

### 操作方法

- ← →：バーを左右に移動
- ボールを床に落とさないように操作します
- すべてのブロックを破壊するとゲームクリアです

## 制作の目的
ステージごとに異なる見た目や雰囲気を持たせ、
プレイヤーが楽しめるステージを制作することを目指しました。

## 担当した部分
- Stage 4のブロック配置
- ステージの背景や演出
- フリーBGMの選定

## 使用技術
- Python
- Pygame

## 工夫した点
海をイメージしたステージにするため、背景やブロックだけでなく、
イルカなどの装飾部分も調整しました。

特にイルカは単色ではなくグラデーションになるように描画処理を変更し、
立体感が出るようにしました。

また、背景には泡の演出を追加し、ステージ全体が海らしく見えるようにしました。

## Web公開
